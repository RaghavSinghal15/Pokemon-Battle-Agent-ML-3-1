# Notebooks

Notebooks are for exploring and for making figures, not for code other people depend on.

- One folder per person or topic: `notebooks/<your-name>/` or `notebooks/<module>/`.
- Clear all outputs before committing (`nbstripout --install` once does this automatically).
- If a function is useful twice, move it into `src/pokeagent/` with a test.
- A figure that goes in the report is regenerated by a script in `scripts/`, not only by a
  notebook cell someone once ran.
